# GRStudio — комплект сайта и админ-панели

Этот комплект рассчитан на Cloudflare Pages, GitHub, D1 и R2.

## Важно
- Я подготовил код и структуру файлов, но не могу войти в ваш Cloudflare/GitHub и создать ресурсы внутри аккаунта.
- Не отправляйте никому пароль администратора и секреты.
- Пока не удаляйте резервную копию прежнего `index.html`.
- Папка `functions` должна находиться в корне репозитория рядом с `index.html`, иначе Pages Functions не заработают.

## Быстрый старт
1. Следуйте `INSTALL_RU.md`.
2. Создайте D1 с именем `grstudio-db`, выполните SQL из `schema.sql`.
3. Создайте R2 bucket с именем `grstudio-media`.
4. Подключите D1 как binding `DB`, R2 как binding `MEDIA`.
5. Добавьте Secrets `ADMIN_PASSWORD` и `SESSION_SECRET`.
6. Загрузите файлы в корень GitHub-репозитория и дождитесь новой публикации.

## Возможности
- публичная адаптивная страница;
- редактирование заголовка, описания, раздела «О студии» и контакта;
- добавление/удаление портфолио: изображения, видео и внешние ссылки;
- D1 для контента и метаданных проектов;
- R2 для загруженных медиафайлов;
- серверная сессия с HttpOnly cookie.

Это стартовый комплект: перед публичным запуском проверьте его в своём аккаунте, сделайте резервную копию и протестируйте вход, загрузку и удаление файлов.
